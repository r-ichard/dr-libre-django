# DrLibre: for any agent

The instructions of this repository are in `CLAUDE.md`. They are written for every agent
and every model, whatever the file is called: read it whole before you change anything.

If you are picking the project up, read `doc/handover.md` next: where it stands, what is
in flight, and the recipes to verify and land a change.

The product is specified in `drlibre-specs.md`, which only the owner edits.
